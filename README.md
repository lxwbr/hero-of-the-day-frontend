# Minimal Next.js App

A very minimal Next.js application with React 19 and Mantine.

## Tech Stack

- **Next.js 15** - React framework
- **React 19** - Latest React
- **Mantine** - UI component library
- **TypeScript** - Type safety

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000)

## Features

- ✅ React 19
- ✅ Mantine UI
- ✅ TypeScript
- ✅ Minimal setup
- ✅ No Tailwind CSS
